## How I work

- Verify every number against the raw data before it gets published, then document the trail
- Report effect sizes, not just p-values; label metrics for what they actually measure
- Write documentation that reads like a person, not an auditor
- Correct my own numbers in public when a re-check proves them wrong

Every case study above has a business page and a technical page on [the portfolio](https://elishabassey.netlify.app), where the reasoning is laid out end to end.
